Systems programming language

Rust

Rust 是一门专注于性能、可靠性和生产力的系统编程语言。它在不依赖垃圾回收器的前提下提供内存安全保证，适合构建高性能服务、工具、嵌入式程序与游戏。

为什么选择 Rust

内存安全

所有权与借用检查在编译阶段发现大量内存和并发问题，减少运行时故障。

可预测的性能

零成本抽象与精细的资源控制，让高级表达能力不必以额外运行时开销为代价。

现代工具链

Cargo、rustfmt 与 Clippy 提供一致的构建、依赖管理、格式化和静态检查体验。
