# 游戏服与接入层文档索引

本目录根层只存放跨模块的游戏服与接入层基础文档，例如 Rust 运行时、帧同步与房间生命周期、接入代理、更新灰度、网络算法和框架路线图。

具体游戏功能按模块放入子目录；模块内保留设计、当前实现边界和 `checklists/`，避免同一功能的设计与验收记录分散。新增文档优先归入已有模块；只有明确会持续扩展的新业务能力才新增模块目录。

| 模块 | 范围 |
| --- | --- |
| [场景与移动](./场景与移动/README.md) | 场景、出生点、坐标、移动同步、AOI 与移动验收 |
| [战斗](./战斗/README.md) | 战斗 ECS、技能、Buff、战斗快照与验收 |
| [背包与物品](./背包与物品/README.md) | 背包、仓库、装备、物品资产事务与奖励交付 |
| [角色与成长](./角色与成长/README.md) | 角色身份、四属性、职业/流派、称号与成长验收 |
| [任务与世界](./任务与世界/README.md) | 任务、进度奖励、世界事件与远行玩法设计 |
| [活动系统](./活动系统/README.md) | 活动公共领域基础、类型契约、生命周期、领奖与奖励交付边界；具体玩法按阶段接入 |

跨模块 checklist 仍保留在根目录 [checklists](./checklists/)；与单一功能模块绑定的 checklist 放在对应模块的 `checklists/`。
