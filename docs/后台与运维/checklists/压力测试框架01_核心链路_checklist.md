# 压力测试框架01：核心链路 Checklist

## 目标

在 Windows 开发工作区交付独立 Rust 工具 `tools/load-test`，完成账号准备、负载校准、安全门禁、指标聚合与报告输出，并支持通过正式玩家入口执行 `auth-http -> game-proxy -> game-server` 核心链路压力测试。

当前 `tools/load-test` 尚未实现；`packages/proto` 以 `.proto` 文件提供共享协议源，`game-proxy` 仍在应用内维护正式 KCP 连接实现，`tools/lockstep-client` 已具备可评估复用的帧同步 scenario 与 `sim-core` 能力。本清单先建立共享边界，再接入真实服务，不把目标态误写为当前实现。

本清单不覆盖周边服务、生产写操作、常驻 Web 管理页面和多机执行；这些内容由 `压力测试框架02_全量服务与扩展_checklist.md` 承接。
