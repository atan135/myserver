- [x] 正式玩家容量只从正式入口和完整流程得出；内部 WSS/gRPC/HTTP 直连仅用于开发或隔离网络的单服务诊断。（验证：配置拒绝 `game-server` 直连；chat/match/mail/announce live gate 限制为 local/test，README 明确不产生正式容量结论。）
- [ ] chat、mail 等玩家服务优先使用 auth 下发的公开 descriptor，内部服务通过 Redis registry 发现，不从固定本地端口推断远程地址。
- [x] 客户端测量值、服务端 metrics 快照和基础设施观测并列关联，不把服务端数据混入客户端直方图。（验证：`ObservationSnapshot` 按 `run_id`/时间窗口独立校验 freshness，`MetricsSnapshot`/分布式聚合只合并客户端原始 HDR 与时间序列；真实服务端和基础设施快照仍待环境 smoke。）
