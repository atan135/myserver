# 通用 Entity 与 AOI 服务端原型 Checklist

## 目标

在 sim-core 实体、movement demo 和场景 grid 基础上构建纯服务端 Entity/AOI 原型，支持实体生命周期、空间索引、兴趣集合、enter/leave 和重连快照。使用测试与 mock-client 验证，不等待正式客户端表现；首期不接 NPC AI、掉落、跨服无缝世界或正式战斗同步。

## 基础原则

- [ ] 逻辑 Entity 与客户端渲染 Entity 分离。
- [ ] AOI 只决定可见/订阅范围，不决定战斗合法性。
- [ ] 结果确定、可测试，不依赖 HashMap 遍历顺序。
- [ ] 原型先在单 Room/单场景内闭环，再设计跨 Room。
